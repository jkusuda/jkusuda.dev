# My Personal Website!

My personal site, built with Next.js, React, Tailwind CSS and GSAP. It opens with a pug whose lines flow across the page and write the text.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it.

## Structure

- `app/` — pages: about (home), projects, blog, Graeme Gallery and contact
- `components/` — shared layout, nav, project tiles and popups, and backgrounds
- `components/intro/` — the pug intro
- `content/blog/` — blog posts, one markdown file each
- `lib/` — project data, and the blog and gallery loaders
- `public/` — images for the site, projects, blog posts and gallery
